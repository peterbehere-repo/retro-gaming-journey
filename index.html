    Sync

    Everything that talks to the hardware lives here: read achievement rows off a handheld, archive its save files, and pull RetroAchievements progress.

    Read the queue

    Handhelds run offline and write unlock rows to a queue on their card. Each row is one way in — MTP over a cable, the card in a reader, or the device's own address on the LAN. Every channel writes an ack back so the device can prune what was taken.

    SD card / handheld volume USB drive not linked

    ArkOS, Spruce and Onion handhelds mount as an ordinary USB drive. Grant the card root once and the page reads the queue straight off it.
