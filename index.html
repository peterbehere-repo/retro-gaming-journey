    Journey map

    The NES route as one continuous trail — twenty path points from the Contra jungle to the final fortress, each with its own artwork and three achievement tiers. Click any number to open that game’s card.

    Iteration 1 scope: NES (5 genres × 20 titles = 100 games). The other five consoles arrive in later iterations — the full 600-title directory is already catalogued behind the scenes.

    Three achievements per game

    Every NES title in the library carries three RetroAchievements picks — easy, intermediate and advanced — chosen by RA's own retro ratio (TrueRatio: points weighted by how rare the achievement is). They are also the three stars on each Journey map path point, so lighting a star here lights it there.

    Sync console

    Handhelds run offline and write unlock rows to a queue on their card. Two channels read that queue, and only two: MTP over a USB cable for Android-class hardware, and the card itself in a reader. Both write an ack back so the device can prune what was taken.

    MTP device (USB cable) checking

    A handheld that presents itself as MTP — any Android-based unit, or a Linux build set to MTP mode — is readable straight from the page over WebUSB. Each storage the device exposes (Internal Storage, SD Card) becomes its own volume, so saves on either card are picked up in one connection.
